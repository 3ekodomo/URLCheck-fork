   Wait, the outer interface border means around the ENTIRE URLCheck interface. The current `setCustomBackground` adds border and background for individual modules (which are element borders?)
   Wait! The problem says:
   "Show element borders: Controls borders around individual interface elements/rows. Default: OFF. When OFF, individual elements must not have borders."
   "Show interface border: Controls ONE continuous outer border around the complete URLCheck interface. Default: OFF. When enabled, draw a single border around the entire main interface/container. The border must surround all relevant URLCheck controls as one unified panel. Do NOT draw separate borders around every child element."

   If we look at `MainDialog.java`:
   ```java

   AndroidUtils.setCustomBackground(block, this);
   // ...
   child = Inflater.inflate(layoutId, parent);
   if (parent == ll) {
       AndroidUtils.setCustomBackground(child, this);
   }
   ```
   So `setCustomBackground` is currently applying to every element!
   If we change `setCustomBackground` to only apply *element borders* (stroke) if `SHOW_ELEMENT_BORDER_PREF` is true.
